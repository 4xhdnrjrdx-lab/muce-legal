Review steps on iPhone

  1. Open this page in Safari and download the WAV. If Safari opens an audio preview, use Share → Save to Files. Find the downloaded file in Files or Safari’s Downloads list.
  2. In Files, share the audio file → Muce. Wait for “Copy saved for Muce”. Share the file, not this webpage link.
  3. Open Muce to finish importing. Check Import results, then open the Library item and tap Play. Muce does not start music automatically.
  4. Share the same file again and reopen Muce to check “Already in Library”. The existing item is reused.

You can also choose the saved WAV using “Import from Files” inside Muce. Telegram and a personal account are not required for this sample.

After import, Muce stores its own on-device copy for offline listening. This page only delivers the test file; it does not offer a media catalog.

Проверка на iPhone

  1. Откройте страницу в Safari и скачайте WAV. Если Safari открыл предпросмотр аудио, выберите «Поделиться» → «Сохранить в Файлы». Найдите скачанный файл в «Файлах» или списке загрузок Safari.
  2. В «Файлах» передайте сам аудиофайл через «Поделиться» → Muce. Дождитесь «Копия сохранена для Muce». Передавайте файл, а не ссылку на эту страницу.
  3. Откройте Muce для завершения импорта. Проверьте «Результаты импорта», откройте песню в медиатеке и нажмите Play. Muce не запускает музыку автоматически.
  4. Повторно передайте тот же файл и откройте Muce: результат «Уже в медиатеке» означает использование существующей песни.

Также можно выбрать сохранённый WAV через «Импорт из Файлов» в Muce. Для этого образца Telegram и личный аккаунт не нужны.

После импорта Muce хранит собственную копию на устройстве для прослушивания без интернета. Эта страница предоставляет только тестовый файл, а не каталог музыки.
